# 🚀 Technical Keywords for Data Careers

This repository provides a **curated list of technical and strategic keywords** for professionals in **Data Science**, **Data Engineering**, and **Data Analysis**. These keywords are designed to improve **ranking on ATS (Applicant Tracking Systems)** like Gupy, Greenhouse, Lever, and others.

Use these keywords in:
- Your resume (PDF or online platforms)
- LinkedIn headline and about section
- GitHub project descriptions and READMEs
- Job application platforms

---

## 🐍 Programming Languages & Data Science Libraries

- `Python`  
- `Pandas`  
- `NumPy`  
- `SciPy`  
- `Scikit-learn`  
- `Matplotlib`, `Seaborn`, `Plotly`  
- `Statsmodels`  
- `TensorFlow`, `Keras`, `PyTorch`  
- `XGBoost`, `LightGBM`, `CatBoost`  
- `PyCaret`, `Dask`, `Polars`  
- `Jupyter Notebook`  
- `Streamlit`

---

## 🧠 Machine Learning & Statistics

- `Linear Regression`, `Logistic Regression`  
- `Decision Trees`, `Random Forest`, `Gradient Boosting`  
- `K-Means`, `DBSCAN`, `PCA`  
- `ARIMA`, `SARIMA`, `Prophet` (Time Series Forecasting)  
- `Feature Engineering`, `Feature Selection`  
- `Hyperparameter Tuning`, `GridSearchCV`, `Cross-Validation`  
- `Model Evaluation`: AUC-ROC, Precision, Recall, F1-Score, RMSE
